## Featured Projects

### AWS DynamoDB Data Deduplication Pipeline

**Technologies:** Python, AWS DynamoDB, Boto3, IAM

A cloud data preprocessing pipeline designed to identify and filter duplicate records before they are stored in DynamoDB.

The project involved:

* Processing structured CSV data
* Validating incoming records
* Checking existing records in DynamoDB
* Removing duplicate entries before persistence
* Using Boto3 for AWS interaction
* Applying least-privilege IAM access
* Testing the workflow against validation datasets

During validation, the pipeline successfully identified and removed **4 duplicate records from a 10-row dataset**, filtering 40% of the redundant entries while maintaining the accuracy of retained records.

### Multi-Zone Smart Irrigation & Cloud Telemetry System

**Technologies:** ESP32, Python, C/C++, MQTT, Firebase Realtime Database, DHT11, Capacitive Moisture Sensors

A multi-zone IoT system designed to automate irrigation while providing remote visibility of environmental and soil conditions.

The system:

```text
Sensors
   ↓
ESP32
   ↓
MQTT
   ↓
Cloud Telemetry
   ↓
Decision Logic
   ↓
Targeted Valve Control
```

Each irrigation zone is monitored independently, allowing the system to make localized decisions based on soil moisture conditions rather than treating the entire field as a single zone.

## My Approach to Troubleshooting

One of the areas I’m particularly interested in is infrastructure troubleshooting.

My approach is simple:

```text
Observe
   ↓
Isolate
   ↓
Investigate
   ↓
Identify
   ↓
Fix
   ↓
Verify
   ↓
Document
```

Rather than immediately changing configurations, I try to understand the actual failure, identify which layer is responsible, verify the evidence, apply the smallest appropriate fix, and then confirm that the system is working as expected.

This is the mindset I’m developing for cloud support and infrastructure roles.
