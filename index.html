PRIMARY PROJECT / 01

AWS DynamoDB Data Redundancy & Deduplication Pipeline

Python · Boto3 · AWS DynamoDB · IAM
Inspect code ↗

Problem

Duplicate records can reduce data quality and create unnecessary storage or processing work as datasets grow.

Approach

Incoming structured data is validated and compared with existing DynamoDB records before persistence.

Engineering decisions

  • DynamoDB for key-based record lookups
  • Boto3 for direct AWS automation
  • Validation before persistence
  • Least-privilege IAM permissions

Why this matters

Detecting redundant records before writing them makes the data pipeline easier to reason about and reduces the need for later cleanup.

CSV → Python validation → Boto3 → IAM → DynamoDB → Unique records
10 records tested
4 duplicates filtered
6 unique records retained
